## How builders should use it

- All dossiers are reviewable research. Entries labelled READY support draft exhibit content, not proof of browser implementation. HOLD, deferred and unresolved entries must not become definitive labels.
- Use each source key with its URL, locator and date meaning. Cross-era source keys intentionally refer to another dossier; retain those references when compiling scene data.
- Keep whitepaper citation, documented influence and context distinct. The whitepaper itself is the anchor work, not its own bibliography entry.
- Quoted source passages are short; caption drafts are original explanatory text, not invented quotations from historical people. Guides and mini-games are fictional teaching devices.
- Dates without a supported exact day remain month/year precision. Don't fill missing days with guesses.
- Music directions are original art proposals, not researched assertions about an inventor's taste. No songs, recordings or ROMs are included.
- Boats have dated historical examples. These are evidence of availability, not universally verified first-invention dates. The draft offshore racer and futuristic concept boat are replaced with evidenced conventional types pending better sources.
- Nothing here changes running code or approves current prop placement, factual labels, network behavior or audio.
